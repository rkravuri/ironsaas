# Compose stack

The laptop platform (ADR-0005): Traefik, PostgreSQL, Azurite (Azure Blob stand-in), OpenBao, and the telemetry stack (OpenTelemetry Collector, Tempo, Loki, Prometheus, Grafana).

Commands live in the root `Makefile`: `make up`, `make up-slim`, `make down`, `make reset`, `make ps`, `make logs`, `make certs`, `make hosts`. The runbook is `docs/guides/local-stack.md`.

Files:

- `compose.yaml` the services, with exact image versions and licences
- `.env` local credentials, generated by `make env`, ignored by git
- `traefik/` static configuration; `traefik/dynamic/` holds the generated TLS file
- `telemetry/` collector, Tempo, Loki and Prometheus configuration; Grafana provisioning and dashboards
- `certs/` the mkcert certificate (generated, ignored by git)
- `scripts/` the helper scripts the Makefile calls
- `units/` the tenant unit template and the generated per-tenant projects (from T14)
