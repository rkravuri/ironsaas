# Products

Business products (first: procure-to-pay) live here, one folder per product, with the same layout and rules as a Foundation module: `Api/`, `Services/`, `Data/`, `Contracts/` (its own project), a `README.md`. Namespace `<Name>` (for example `Procurement`), schema `<name>`.

Product work starts after slice S2 (PRD section 7).
